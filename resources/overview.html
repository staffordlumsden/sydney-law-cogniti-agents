Sydney Law School Cogniti Agent Hub — Current Resource Overview

Updated: 3 September 2026

This repository consolidates Sydney Law School Cogniti agent guidance into a self-contained set of resources. Supporting material that previously linked to Notion, Canvas, SharePoint or other external pages has been reproduced or rewritten here so the substantive guidance is available directly on GitHub and on the GitHub Pages site.

Current tools

LexiDraft

LexiDraft is a specialist feedback and revision assistant for advanced legal writing, particularly in Honours and selected capstone contexts. It is designed to support students' own analysis and writing rather than generate the assessment for them.

Current supplied version: v1.1_09052025 [Experimental]

ChatGPT 5.4 for Sydney Law School

ChatGPT 5.4 for Sydney Law School is the current general-purpose Cogniti workspace for low-risk legal education tasks such as rubrics, scenarios, formative activities, explanations, instructional content and Canvas quiz preparation.

Earlier guides in the supplied material referred to ChatGPT4o and, in places, o3-mini. Those references have been updated in the current repository resources to ChatGPT 5.4 for Sydney Law School while retaining the useful workflows.

Unit Outline Helper

Unit Outline Helper supports drafting and review of ULOs, assessment summaries and curriculum alignment for Sydney Curriculum (AKARI).

Current supplied version: v1.2_29042025

The supplied guide described an earlier ChatGPT4o configuration. Because the current underlying model for Unit Outline Helper is not identified in the supplied material, this repository does not assert a replacement model name.

AI Student Support Chatbot

The AI Student Support Chatbot is a related staff-support tool for identifying relevant information and possible next actions when a student may need non-academic assistance. It is described separately because its purpose is support navigation rather than curriculum or teaching-content generation.

It draws on the University's Red Book – Specialist Advice and Support for Students 2024. This repository includes the supplied description and safeguards, but not the full Red Book, because the Red Book itself was not among the supplied source files.
